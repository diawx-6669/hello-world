# 🌐 FlowMind · Liquidity OS

**FlowMind** — это высокопроизводительная веб-платформа (Liquidity OS), предназначенная для мониторинга глобальных финансовых транзакций, управления платежной инфраструктурой и аналитики в реальном времени. Система разработана с акцентом на скорость, удобство интерфейса и масштабируемость.

---

## 🛠 Технологический стек
* **Frontend:** Чистый JavaScript (ES6+), HTML5, CSS3.
* **Архитектура:** Модульная структура с разделением ответственности (UI, Data, Search, App Logic).
* **Стилизация:** Использование современных CSS-переменных, Flexbox/Grid и шрифтов *Space Grotesk* и *JetBrains Mono*.
* **Интеграции:** Tabler Icons для визуализации интерфейса.

---

## 📂 Структура проекта (Модульная система)
Проект построен по принципу разделения логики на специализированные модули:

- `index.html`: Главная точка входа. Организует работу Sidebar, Topbar и контентных областей.
- `js/app.js`: **Core.** Управляет навигацией, жизненным циклом приложения, API-запросами и восстановлением сессий пользователей.
- `js/ui.js`: **UI Engine.** Отвечает за рендеринг динамических данных: пульс транзакций, карточки систем оплаты, уведомления (Toast).
- `js/data.js`: **Configuration.** Хранит конфигурации регионов (Европа, Азия и др.), платежных систем и данные для симуляции транзакций.
- `js/search.js`: **Global Search.** Интеллектуальный поиск с debounce-эффектом и API-интеграцией.
- `css/style.css`: Глобальная таблица стилей, определяющая дизайн-систему приложения.

---

## 🚀 Ключевые особенности

### 1. Интеллектуальный мониторинг (Pulse Feed)
Система имитирует поток транзакций в реальном времени (`SWIFT`, `SEPA`, `CARD`). Каждый тип транзакции имеет свою цветовую маркировку и иконку, что позволяет мгновенно оценивать состояние ликвидности.

### 2. Географическая сегментация
FlowMind динамически переключает доступные платежные системы в зависимости от выбранного региона:
* **Европа:** SEPA, SWIFT, Target2, Kartuli.
* **Азия:** SWIFT, CIPS.
* **Ближний Восток:** SSNIP, MEPA.

### 3. Динамический поиск
Интегрированный поисковый модуль позволяет мгновенно фильтровать данные. При отсутствии ответа от API система автоматически переключается на локальный поиск по конфигам.

### 4. Управление сессиями
Автоматическое сохранение состояния пользователя в `localStorage`, что обеспечивает бесшовный опыт взаимодействия при перезагрузке страницы.

## ⚙️ Установка и использование
1. Клонируйте репозиторий.
2. Проект не требует сборки (build-less). Достаточно открыть `index.html` в современном браузере.
3. Убедитесь, что все файлы находятся в соответствующих папках (`/css`, `/js`), так как проект использует относительные пути.

## 🤝 Вклад в проект
Данный проект является отличной базой для создания **FinTech-дашбордов**. 
* Для добавления новых регионов — редактируйте `js/data.js`.
* Для изменения логики рендеринга данных — смотрите методы в `js/ui.js`.
* Для добавления новых типов анимации или графиков — используйте `css/style.css`.
